# Mi primer post

¡Bienvenido al blog! Este es el primer artículo publicado en este sitio estático construido con tecnologías web fundamentales.

## ¿Qué encontrarás aquí?

En este blog compartiré conocimientos sobre desarrollo web, herramientas de código abierto y mejores prácticas para crear sitios web modernos y accesibles.

### Tecnologías utilizadas

Este blog está construido exclusivamente con:

- **HTML5** para la estructura
- **CSS3** para los estilos y diseño responsive
- **JavaScript** vanilla para la interactividad
- **Markdown** para el contenido de las publicaciones
- **Marked.js** para interpretar Markdown en el navegador

> No se utilizan frameworks, compiladores ni procesos de construcción. Solo archivos estáticos servidos directamente por GitHub Pages.

## Código de ejemplo

Un simple "Hola Mundo" en JavaScript:

```javascript
function saludar(nombre) {
  console.log(`¡Hola, ${nombre}! Bienvenido al blog.`);
}

saludar('Mundo');
```

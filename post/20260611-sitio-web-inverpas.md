# [Proyecto] Sitio Web Inverpas

Sitio web la empresa Inverpas Ingeniería SpA desarrolla soluciones IoT y de telemetría para la gestión inteligente del agua, integrando ingeniería especializada, automatización, plataforma cloud propia y monitoreo en tiempo real. Sus sistemas garantizan cumplimiento normativo ante la DGA, alta disponibilidad, seguridad física y digital, respaldo de información, operación autónoma y herramientas de análisis que permiten optimizar la administración de los recursos hídricos con máxima confiabilidad.

## Datos técnicos

Página web programada sobre el Framework PHP Fat Free Framework, se utiliza Bootstrap 5 para el apartado visual, javascript, jquery y otras librerías similares para la parte funcional, el sistema esta montado en un servidor Apache Estandar.Utiliza el servicio interno del servidor para el envio de los correos del formulario de contacto.

## Tecnologías utilizadas

- Fat Free Framework

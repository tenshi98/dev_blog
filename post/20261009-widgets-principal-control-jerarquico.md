# Widgets de la pantalla principal con control jerárquico (bloque + sub-widgets)

La pantalla de Orden de Widgets ahora organiza los widgets en bloques con un interruptor maestro, y dentro de cada bloque cada sub-widget tiene su propio interruptor. Esto permite activar o desactivar por separado elementos que antes aparecían pegados, como Compras y Ventas de Documentos Mercantiles, o las cuatro tarjetas de Campañas.

## Qué cambia

Ahora el administrador tiene control total sobre cómo se muestra la pantalla principal, en dos niveles:

- **Nivel bloque**: cada grupo (Gestión Bodegas y Productos, Gestión Documentos Mercantiles, Gestión Campañas, Reservas) tiene un interruptor maestro y se puede arrastrar como una unidad para posicionarlo.
- **Nivel sub-widget**: dentro de cada bloque, cada elemento se enciende o apaga de forma individual y se reordena dentro del bloque.

Ejemplo práctico: en Gestión Documentos Mercantiles, Compras y Ventas ahora son tarjetas independientes que se muestran u ocultan por separado (antes salían juntas siempre). En Gestión Campañas, sus cuatro tarjetas (Resumen, Comparación Semanal, Análisis Contable y Últimas partidas confirmadas) se controlan una a una.

Todos los elementos de la pantalla de Orden de Widgets muestran su propio switch de activación/desactivación, tal como se solicitó.
